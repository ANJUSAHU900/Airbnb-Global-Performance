# 📊 Airbnb Listings & Performance Dashboard (Power BI)

An interactive Power BI dashboard analyzing Airbnb listings, pricing trends, occupancy rates, and customer reviews.

---

## 📌 Project Overview
- Designed an end-to-end interactive Power BI dashboard to track key business metrics (KPIs).
- Evaluated revenue, average price per night, and review ratings across room types and locations.
- Implemented dynamic filters and slicers for seamless exploration by property type and price range.

---

## 🛠️ Tech Stack & Skills
- **BI Tool:** Microsoft Power BI Desktop
- **Data Modeling:** Star Schema / Relationships
- **Calculations:** DAX (Measures & Calculated Columns)
- **Visuals Used:** KPI Cards, Donut Charts, Bar Charts, Decomposition Tree, Geospatial Maps

---

## 🔍 Key Dashboard Insights
- **Pricing Trends:** Identified optimal price points and peak booking categories.
- **Customer Ratings:** Analyzed review distribution to highlight high-performing listings.
- **Occupancy & Demand:** Visualized location-wise demand patterns to assist decision-making.
